# UI Notes

## Overall visual style

The product should feel:
- minimal
- modern
- clean
- light
- personal
- calm
- premium but simple

Main influence:
- minimal iOS-style interface
- bento-style dashboard composition

## Default theme

- light mode first
- dark mode can come later
- neutral surfaces
- black text
- soft borders
- subtle shadows only if needed

## Layout principles

- mobile-first
- generous spacing
- rounded cards
- strong readable typography
- simple hierarchy
- easy scanning
- avoid clutter

## Dashboard direction

The dashboard should feel like a personal control center.

Possible tile types:
- active activity
- progress summary
- quick add
- latest run
- trend card
- stats card
- focus card
- recent activity list

Tiles can vary in size:
- 2x1
- 2x2
- 4x2
- full width on mobile

## Key UI elements

### Buttons
- simple
- rounded
- strong primary CTA
- secondary buttons lighter and calmer

### Cards
- rounded corners
- subtle border
- clean padding
- not too much decoration

### Progress
- clear and visual
- progress bar from 0 to 100
- percentage visible
- strong readability

### Data
- elapsed time should be visually important
- trend should be easy to understand at a glance
- comparisons should feel simple, not analytical

## Avoid

- overly glossy UI
- tech / space visual overload
- crowded dashboard
- too many accent colors
- too many badges or indicators
- overly enterprise-looking components

## Tone of product

The product should feel:
- direct
- useful
- motivating
- non-judgmental
- slightly “smart”
- visually calm
